# 請求書ジェネレーター

Asobo matsudo sports! studio（運営：株式会社RED MAX）の請求書フォーマットに合わせた、ブラウザだけで動く請求書作成ツールです。サーバーやアカウント登録は不要で、入力した内容はそのブラウザの中だけに保存されます。

**公開URL：** https://red-create-lab.github.io/invoice-generator/

## できること
- 発行日・請求書番号・宛先・支払期限・明細・備考を入力すると、右側にロゴ入りの請求書デザインでその場でプレビューされます
- 明細は行の追加・複写・削除が可能
- 消費税率を指定すると、小計（税抜）／消費税／ご請求金額（税込）を自動計算
- 「印刷 / PDFで保存」ボタンから、ブラウザの印刷機能でPDF保存や印刷が可能
- 入力内容はブラウザのlocalStorageに自動保存され、閉じて再度開いても内容が残る（「入力内容をクリア」でリセット可能）
- 会社名・住所・電話番号・振込先（銀行名／支店名／口座種別／口座番号）は初期値が入っていますが、「会社情報・振込先を編集」から変更可能

## 使い方
1. 上記の公開URLをブラウザで開く
2. 左側のフォームに必要事項を入力（明細は「＋ 明細行を追加」で増やせます）
3. 右側のプレビューを確認
4. 「印刷 / PDFで保存」を押し、印刷ダイアログで「PDFとして保存」を選択

## 技術構成
- 単一の `index.html` ファイルのみ（外部ライブラリ・ビルド不要）
- GitHub Pagesでそのまま公開（`main` ブランチの `/ (root)` を配信）
- ロゴ画像はBase64化してHTML内に埋め込み済み

## 更新方法
`index.html` を直接編集し、`main` ブランチにpushすると、数十秒〜数分で公開URLに反映されます。変更内容は [CHANGELOG.md](./CHANGELOG.md) に追記してください。

## バージョン履歴
最新バージョンは `index.html` 内フォーム下部の表示（例：v1.1）で確認できます。詳細は [CHANGELOG.md](./CHANGELOG.md) を参照してください。
